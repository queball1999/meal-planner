{{icon "code"}} Headless browser & anti-bot

Most grocery sites block plain HTTP requests or render their prices in JavaScript. Configure a headless browser and/or FlareSolverr below, and scraping escalates to them automatically when a direct fetch comes back as a challenge page or an empty shell. Changes save immediately - no restart needed.

  • FlareSolverr - solves Cloudflare-style anti-bot challenges. Used as the second attempt whenever its URL is set, even alongside browserless. Use when a store returns 403 or "Just a moment".
  • browserless - runs the page's JavaScript and returns the rendered HTML (browserless/chromium or anything exposing POST /content). Use when the page loads but has no prices in its markup.

docker-compose.yml already includes both services - comment out either block if you don't need it, then set the URL to http://browserless:3000 (same Docker network) or http://localhost:3900.
