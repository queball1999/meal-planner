{{/* ── Headless browser (scraping) ─────────────────────────────────── */}}


    
{{icon "code"}} Headless browser

    

        Most grocery sites block plain HTTP requests or render their prices in JavaScript.
        Point Go Eat at a headless browser and scraping escalates to it automatically when a
        direct fetch comes back as a challenge page or an empty shell.
        Configure RENDER_BACKEND, RENDER_URL and
        RENDER_TOKEN in the Scraping section below - changes take
        effect immediately, no restart.
    

    
    
        
  • flaresolverr - solves Cloudflare-style anti-bot challenges. Use when a store returns 403 or "Just a moment".
    • 
        
  • browserless - runs the page's JavaScript and returns the rendered HTML
            (browserless/chromium or anything exposing POST /content).
            Use when the page loads but has no prices in its markup.
    • 
    

    

        docker-compose.yml already includes both services - comment out either
        block if you don't need it, then set the URL to http://browserless:3000
        (same Docker network) or http://localhost:3900.
